# Корреляционная иммунность

## Контекст

Метрика устойчивости функций к **корреляционным атакам** (Siegenthaler) в **потоковых шифрах**. Для S-блоков 8×8 в блочных шифрах ставится редко — но определение важно, поскольку формулируется через [[walsh-hadamard|ПУА]] и связано с [[balancedness]].

## Три эквивалентных определения

**Статистическое.** $f$ — корреляционно-иммунна порядка $m$ (КИ-$m$), если она статистически независима от любого подмножества из $m$ своих переменных:
$$\forall I = \{i_1, \dots, i_m\}: \quad X^{(I)} \perp f(X^{(1)}, \dots, X^{(n)}).$$

**Теоретико-информационное.** Взаимная информация $I(X^{(I)}, f) = 0$ для всех подмножеств $|I| = m$.

**Комбинаторное.** Все подфункции от $n-m$ переменных (полученные подстановкой констант) имеют одинаковый вес — $w(g) = w(f)/2^m$.

Эквивалентность доказана в `raw/coursework-1/content.tex:546–561`.

## Спектральный критерий

$$f \text{ КИ-}m \iff \hat{f}(a) = 0 \quad \forall a: 1 \leq w(a) \leq m.$$

Если дополнительно $f$ [[balancedness|сбалансирована]] — называется **m-устойчивой**:
$$f \text{ m-устойчива} \iff \hat{f}(a) = 0 \quad \forall a: 0 \leq w(a) \leq m.$$

## Криптографический смысл

В потоковых шифрах с фильтрующей булевой функцией $f$ выходной бит = $f(\text{состояние LFSR})$. Если $f$ статистически коррелирует с подмножеством входных битов — атакующий восстанавливает биты регистра по выходному потоку. Высокая корреляционная иммунность блокирует это.

## Trade-off с другими свойствами

Корреляционная иммунность конфликтует с [[algebraic-degree|алгебраической степенью]]: по теореме Зигенталера, для сбалансированной функции $\deg f + m \leq n - 1$.

## Реализация

В коде не реализована — для S-блоков 8×8 в блочных шифрах не критична. Если понадобится в дальнейшем (например, при выходе на потоковые шифры), достаточно реализации через спектральный критерий: проверить `BoolFunc.Walsh()` на нули в нужных позициях.

# S-блок SM4

## Контекст шифра

- Стандарт: GM/T 0002-2012 (Китай, национальный криптографический стандарт).
- Разработчик: OSCCA (Государственное бюро криптографии КНР).
- История: впервые опубликован в 2006 в контексте WLAN; принят как национальный стандарт в 2016; продвигается как альтернатива AES в государственных и коммерческих системах Китая.
- Структура: обобщённая сеть Фейстеля.
- Блок: 128 бит. Ключ: 128 бит. Раунды: 32.
- Раундовая функция $T = L \circ \tau$, где $\tau$ — побайтовое применение S-блока, $L$ — линейное преобразование.

## Конструкция S-блока

Один статичный 8-битный S-блок. Происхождение долгое время **официально не раскрывалось** — ситуация, схожая с [[kuznechik-sbox|«Кузнечиком»]].

Криптографический анализ показал: построен по принципу [[aes-sbox|AES]]:
$$S(x) = A \cdot x^{-1} + b \quad \text{в } \mathbb{F}_{2^8},$$
с **другим неприводимым полиномом** для $\mathbb{F}_{2^8}$ и иной аффинной парой $(A, b)$.

Таблица — `testdata/sm4_sbox.json`.

## Метрики

| Метрика | Значение | Совпадение с AES |
|---|---|---|
| [[nonlinearity\|Нелинейность]] $N$ | 112 | ✓ |
| [[differential-uniformity\|Дифференциальная равномерность]] $\delta$ | 4 | ✓ |
| [[algebraic-degree\|Алгебраическая степень]] $\deg$ | 7 | ✓ |

Метрики **идентичны AES** — что естественно при одинаковой конструкции (инверсия в $\mathbb{F}_{2^8}$).

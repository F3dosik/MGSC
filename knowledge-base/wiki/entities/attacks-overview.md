# Карта: атаки → метрики S-блока → свойства булевых функций

## Главная сводка

Центральная идея 2-й курсовой: каждой атаке соответствует своя метрика стойкости S-блока, и каждая метрика выражается через свойство [[boolean-function-basics|булевых функций]] (связь с 1-й курсовой).

| Атака | Метрика S-блока | Свойство булевой функции | Целевой порог | Реализация в коде |
|---|---|---|---|---|
| [[linear-cryptanalysis\|Линейный криптоанализ]] (Matsui 1993) | $L(S)$ — линейность; $N(S)$ — нелинейность | [[nonlinearity\|нелинейность]] $N_f = \min_\beta N(f_\beta)$ | $N \geq 112$ | `boolfunc/metrics.go:27`, `sbox/analysis.go:27` |
| [[differential-cryptanalysis\|Дифференциальный криптоанализ]] (Biham-Shamir 1990) | $\delta(S)$ — дифференциальная равномерность | [[directional-derivative\|производная по направлению]] $S'_a$ → [[differential-uniformity\|DDT]] | $\delta \leq 4$ | `sbox/ddt.go:37` |
| [[higher-order-differential-attack\|Higher-order differential]] (Lai 1994) | $\deg(S)$ — алг. степень | [[algebraic-degree\|алг. степень]] $\max_\beta \deg(f_\beta)$ | $\deg \geq 7$ | `boolfunc/metrics.go:36`, `sbox/analysis.go:36` |
| [[algebraic-attack\|Алгебраическая атака]] (Courtois-Meier 2003) | $AI(S)$ — алг. иммунность | [[algebraic-immunity\|алг. иммунность]] $\min_\beta AI(f_\beta)$ через [[annihilator\|аннигиляторы]] | $AI \geq 3$ | `boolfunc/metrics.go:122`, `sbox/algebraic.go:6` |

## Важный нюанс — связь $\delta$ с булевой функцией

Из четырёх метрик три ($N, \deg, AI$) являются **агрегатами** компонентных функций $f_\beta(x) = (\beta, S(x))$ через `min`/`max` по $\beta$. Дифференциальная равномерность $\delta$ — **исключение**: она определена напрямую через DDT таблицы $S$, а не через компоненты.

Связь $\delta$ с булевыми функциями идёт через [[directional-derivative|производную по направлению]] — производная $S'_a$ сама является векторной булевой функцией $\mathbb{F}_2^n \to \mathbb{F}_2^n$, а DDT регистрирует распределение её значений.

Это видно и в коде:
- `boolfunc/` (метрики булевых функций) — содержит NL, deg, AI, но **не содержит** $\delta$.
- `sbox/ddt.go` — считает $\delta$ напрямую по таблице $S$.

При формулировке во введении курсовой стоит уточнить: «три метрики ($N$, $\deg$, $AI$) выражаются как агрегаты свойств компонентных булевых функций; $\delta$ — через производные по направлению».

## Двойственность LC ↔ DC

Линейный и дифференциальный криптоанализ — «зеркальные» атаки. У них общая структура:

| Аспект | LC | DC |
|---|---|---|
| Параметр S-блока | $LAT[\alpha, \beta]$ | $DDT[\Delta X, \Delta Y]$ |
| Метрика | $L(S) = \max\|LAT\|$ | $\delta(S) = \max DDT$ |
| Тип атаки | known plaintext | chosen plaintext |
| Объём | $N_L \approx 1/\varepsilon^2$ | $N_D \approx c/p_D$ |
| Сборка атаки на шифр | piling-up по active S-boxes | произведение вероятностей по active S-boxes |
| Тонкость | linear hulls (Nyberg) | differentials = $\cup$ characteristics |

В обеих атаках общий принцип защиты — **минимизировать максимум** метрики S-блока + **максимизировать число активных S-блоков** в любом раунде через дизайн линейного слоя.

## Двойственность higher-order diff. ↔ algebraic attack

Эти две атаки — также пара, но «обратная»:

| Аспект | Higher-order differential | Algebraic attack |
|---|---|---|
| Что эксплуатирует | низкую $\deg f$ — производные обнуляются | низкое $AI$ — низкостепенный аннигилятор |
| Защита | $\deg f \to n$ | $AI \to \lceil n/2 \rceil$ |
| Связь | работают «через» друг друга, но независимо: высокая $\deg$ ≠ высокая $AI$ | |

## Применимость

| Атака | Блочные шифры | Потоковые шифры |
|---|---|---|
| LC | ✓ основной критерий | ограничено |
| DC | ✓ основной критерий | ограничено |
| Higher-order | ограничено (требует low-degree round function) | ✓ |
| Algebraic | ограничено | ✓ основная мотивация |

Для нашего фокуса — биективные S-блоки 8×8 для блочных шифров типа SPN — все четыре атаки **актуальны** как критерии при анализе и генерации.

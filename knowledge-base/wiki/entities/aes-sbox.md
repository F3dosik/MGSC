# S-блок AES (Rijndael)

## Контекст шифра

- Стандарт: NIST FIPS 197 (2001).
- Авторы: Joan Daemen, Vincent Rijmen (Бельгия).
- История: победитель открытого конкурса NIST (1997–2001) на замену DES.
- Структура: SPN (substitution-permutation network).
- Блок: 128 бит. Ключ: 128/192/256 бит. Раунды: 10/12/14.
- Преобразования раунда: SubBytes, ShiftRows, MixColumns, AddRoundKey.

## Конструкция S-блока

Единственный статичный 8-битный S-блок. Конструкция:
$$S(x) = A \cdot x^{-1} + b \quad \text{в } \mathbb{F}_{2^8},$$
где:
- $x^{-1}$ — мультипликативная инверсия в $\mathbb{F}_{2^8} = \mathbb{F}_2[X] / (X^8 + X^4 + X^3 + X + 1)$ (по соглашению $0^{-1} = 0$);
- $A$ — фиксированная аффинная $8 \times 8$ матрица над $\mathbb{F}_2$;
- $b = (0,1,1,0,0,0,1,1)$.

Таблица — `testdata/aes_sbox.json`.

## Метрики

| Метрика | Значение | Соответствие порогам |
|---|---|---|
| [[nonlinearity\|Нелинейность]] $N$ | 112 | максимум для биективных 8×8 в этом классе конструкций |
| [[differential-uniformity\|Дифференциальная равномерность]] $\delta$ | 4 | минимум для биективных 8×8 при чётном $n$ |
| [[algebraic-degree\|Алгебраическая степень]] $\deg$ | 7 | максимум для биективной 8×8 |
| Биективность | да | — |

При теоретическом максимуме нелинейности 120 ([[bent-functions|бент]]) для несбалансированных — AES даёт 112. Эти значения = практические пороги, заложенные в [[thesis-statement|постановку задачи]] и [[fitness-function-sbox|fitness]].

## Особенности

- **Компактное алгебраическое описание** — потенциально уязвимо к алгебраическому анализу (см. также [[kuznechik-sbox]], [[sm4-sbox]], [[camellia-sbox]] — построены по тому же принципу).
- Является **точкой отсчёта** для сравнения. В [[reference-sboxes-metrics]] — сводка всех 6 эталонных шифров.

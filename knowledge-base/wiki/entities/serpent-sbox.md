# S-блоки Serpent

## Контекст шифра

- Авторы: Ross Anderson (UK), Eli Biham (IL), Lars Knudsen (DK), 1998.
- История: финалист конкурса AES, **2-е место** (наибольшее число голосов среди участников, ставивших приоритетом максимальную безопасность в ущерб производительности).
- Блок: 128 бит. Ключ: 128/192/256 бит. Раунды: **32** (вдвое больше AES — консервативный подход с запасом стойкости).
- Эффективная реализация: **bitslicing** — несколько блоков параллельно.

## Конструкция S-блоков

- Восемь **различных 4-битных** S-блоков, применяемых **циклически по раундам**.
- Каждый — биективное $\{0,1\}^4 \to \{0,1\}^4$.
- Получены из S-блоков DES с оптимизацией по критериям дифференциальной и линейной стойкости.

## Метрики

| Метрика | Значение | Контекст |
|---|---|---|
| [[nonlinearity\|Нелинейность]] каждого S-блока | 4 | максимум для 4-битных биективных |
| Дифференциальная вероятность | оптимальная для 4 бит | — |

Совокупная стойкость Serpent к линейному и дифференциальному криптоанализу **превосходит AES** благодаря 32 раундам (vs 10–14).

## Особенности по сравнению с 8-битными S-блоками

Serpent — единственный из 6 эталонных шифров с 4-битными S-блоками. Для **этой курсовой важен как контраст:** наши целевые пороги ($N \geq 112$, $\delta \leq 4$) сформулированы для 8-битного случая и к Serpent не применяются напрямую. Но Serpent иллюстрирует альтернативный design-choice: маленькие S-блоки + больше раундов.

# Преобразование Мёбиуса

## Определение

Если функция $f$ представлена в [[algebraic-normal-form|АНФ]]:
$$f(x) = \bigoplus_{a \in \mathbb{Z}_2^n} g(a) \cdot x_1^{a_1} \cdots x_n^{a_n},$$
то отображение
$$\mu: \mathcal{F}_n \to \mathcal{F}_n, \quad \mu(f) = g,$$
называется **преобразованием Мёбиуса**, а значения $g(a)$ — коэффициентами АНФ.

## Прямая формула

$$g(a) = \bigoplus_{x \leq a} f(x),$$
где $x \leq a$ означает $x_i \leq a_i$ для всех $i$ (частичный порядок на векторах из $\mathbb{Z}_2^n$).

Доказательство по индукции на вес $a$ — `raw/coursework-1/content.tex:250–279`.

## Обращение

$$f(x) = \bigoplus_{a \leq x} g(a).$$

## Инволютивность

$$\mu(\mu(f)) = f.$$

Преобразование Мёбиуса само себе обратное — этим оно отличается от ПУА, для которого обратное содержит масштабирующий множитель $2^{-n}$.

## Связи

- [[algebraic-normal-form|АНФ]] вычисляется применением $\mu$ к таблице истинности.
- [[algebraic-degree]] = max степень монома в результате $\mu(f)$.
- [[walsh-hadamard|ПУА]] — другое спектральное преобразование, вычисляет иной набор характеристик.

## Быстрый алгоритм

Внешний цикл по битам $i = 0, \dots, n-1$; на каждом уровне для всех пар индексов, различающихся только в $i$-м бите, выполняется $g[a] \mathrel{\oplus}= g[a \oplus (1 \ll i)]$.

Итого $O(n \cdot 2^n)$ операций.

## Реализация

- `boolfunc/transforms.go:8` — `moebiusInPlace(f []uint8, n int)`: in-place преобразование, $O(n \cdot 2^n)$ XOR-операций.
- `boolfunc/transforms.go:23` — `BoolFunc.ANF()`: копирует TV, применяет `moebiusInPlace`, кэширует результат как `BoolFunc.anf`.

Идея алгоритма: внешний цикл по битам $i = 0, \dots, n-1$; на каждом уровне для пар $(a, a \oplus 2^i)$ выполняется $f[a + 2^i] \mathrel{\oplus}= f[a]$.

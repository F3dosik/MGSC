# Дифференциальный криптоанализ (DC)

## Идея

Предложен **Biham, Shamir** (CRYPTO '90, журнал 1991). Для идеального рандомизирующего шифра при фиксированной входной разности $\Delta X$ распределение выходной разности $\Delta Y$ равномерно: $P(\Delta Y \mid \Delta X) = 1/2^n$. Дифференциальный криптоанализ ищет пары $(\Delta X, \Delta Y)$, для которых $p_D = P(\Delta Y \mid \Delta X) \gg 1/2^n$.

Такая пара называется **дифференциалом**. Атакующий выбирает пары открытых текстов $(X', X'')$ с заданной разностью $\Delta X = X' \oplus X''$ и наблюдает выходную разность — это **chosen plaintext attack** (в отличие от LC, который known plaintext).

## Почему ключ не мешает

В шифрах с key-XOR (как SPN) ключевые биты **не влияют на входную разность** S-блока:
$$\Delta W = W' \oplus W'' = (X' \oplus K) \oplus (X'' \oplus K) = X' \oplus X'' = \Delta X.$$

Это значит: **DDT keyed S-блока совпадает с DDT unkeyed** — атакующий может анализировать S-блок без знания ключа. Ключ влияет только на сдвиг конкретных значений $X, Y$, но не на их разности.

## Связь со свойством S-блока

[[directional-derivative|Производная по направлению]] $S'_a(x) = S(x) \oplus S(x \oplus a)$ — это и есть «как $S$ преобразует разность $a$». Распределение её значений по всем $x$ записывается в строку $a$ таблицы [[differential-uniformity|DDT]]:
$$DDT[a, b] = |\{x : S(x \oplus a) \oplus S(x) = b\}|.$$

**Метрика стойкости** — [[differential-uniformity|дифференциальная равномерность]] $\delta(S) = \max_{a \neq 0, b} DDT[a, b]$.

## Дифференциальная характеристика

Шифр атакуют через **дифференциальную характеристику** — последовательность разностей $(\Delta U_1, \Delta V_1, \Delta U_2, \dots)$ по раундам, выстраиваемую сцеплением дифференциалов отдельных S-блоков:
- разности по нелинейному слою: $\Delta V_i = $ из соответствующей строки DDT с вероятностью $\beta_i = DDT[\Delta U_i, \Delta V_i] / 2^n$;
- по линейному слою (перестановка/MDS): детерминированно.

При предположении независимости S-блоков:
$$p_D = \prod_{i=1}^\gamma \beta_i,$$
где $\gamma$ — число **активных S-блоков** (с ненулевым $\Delta U$).

## Active S-boxes

**Активный S-блок** в характеристике — тот, у которого $\Delta U \neq 0$. Чем больше активных и чем меньше вероятности дифференциалов в каждом — тем меньше $p_D$.

**Общий подход к стойкости** (как сформулировано в Heys 2002, §4.5):
1. Минимизировать $\delta(S)$ (= минимизировать максимум пары $(\Delta X, \Delta Y)$ S-блока).
2. Спроектировать линейный слой так, чтобы число активных S-блоков было высоким для любой характеристики.

AES — образец дизайна с этой целью: MDS-матрица в MixColumns гарантирует минимум 5 активных S-блоков за 2 раунда.

## Сложность атаки

Число chosen plaintext пар:
$$N_D \approx c / p_D,$$
где $c$ — небольшая константа. Это аналог формулы $N_L \approx 1/\varepsilon^2$ из [[linear-cryptanalysis|LC]].

## Differentials vs Characteristics

Несколько разных характеристик с одинаковыми $(\Delta X, \Delta Y)$ комбинируются — суммарная вероятность дифференциала $\geq$ вероятности любой одной характеристики. Это аналог [[linear-cryptanalysis|linear hulls]].

Для **доказательства стойкости** к DC нужно ограничить вероятность *всех дифференциалов*, а не только характеристик. На практике, если у самой вероятной характеристики $p_D$ высока, она доминирует — и оценка $p_D$ через её вероятность достаточно точна.

## Расширения

- **Truncated differential** (Knudsen 1995) — атакующий предсказывает только некоторые биты $\Delta Y$.
- **Impossible differential** (Biham-Biryukov-Shamir 1999) — эксплуатируется *несуществование* пар $(\Delta X, \Delta Y)$.
- **Higher-order differential** (Lai 1994) — производные более высокого порядка; см. [[higher-order-differential-attack]] — это 4-я атака в этой работе.
- **Differential-linear cryptanalysis** (Hellman, Langford 1994) — комбинация.

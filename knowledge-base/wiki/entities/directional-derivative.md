# Производная по направлению

## Определения

**Частная производная** $f$ по $i$-й переменной:
$$\frac{\partial f}{\partial x_i} = f(x_1, \dots, x_i, \dots, x_n) \oplus f(x_1, \dots, x_i \oplus 1, \dots, x_n).$$

То есть $\partial f / \partial x_i = 1$ ⇔ при изменении $x_i$ значение $f$ меняется при тех же остальных аргументах. Функция $f$ **линейно зависит** от $x_i$ ⇔ $\partial f / \partial x_i \equiv 1$.

**Производная по направлению $a \in \mathbb{Z}_2^n$:**
$$f'_a(x) = f(x) \oplus f(x \oplus a).$$

Это XOR-разница между значением функции в точке $x$ и в точке, сдвинутой на $a$.

## Свойства

1. $f'_0 \equiv 0$.
2. $f'_a(x) = f'_a(x \oplus a)$ — производная симметрична относительно сдвига на $a$.
3. $(f \oplus g)'_a = f'_a \oplus g'_a$.
4. $f'_{a \oplus b}(x) = f'_a(x) \oplus f'_b(x \oplus a)$.

Полный список свойств с доказательствами (включая производную произведения и дизъюнкции) — `raw/coursework-1/content.tex:584–670`.

## Криптографический смысл — связь с DDT

Производная по направлению — **формальная основа [[differential-uniformity|дифференциальной равномерности]]** и таблицы разностного распределения ([[differential-distribution-table|DDT]]).

Для S-блока $S: \mathbb{Z}_2^n \to \mathbb{Z}_2^n$:
$$DDT(a, b) = |\{x : S(x) \oplus S(x \oplus a) = b\}|.$$

То есть DDT считает, сколько раз производная $S'_a$ принимает значение $b$.

Если для некоторого ненулевого $a$ значение $b$ встречается слишком часто (т.е. $S'_a$ «слишком предсказуема») — это эксплуатируется в **дифференциальном криптоанализе** (Biham–Shamir, 1990). Цель проектирования S-блока — равномерное распределение значений $S'_a$ по всем ненулевым $a$, что выражается малой [[differential-uniformity|дифференциальной равномерностью]].

См. также параллельный анализ через линейную аппроксимацию ([[linear-cryptanalysis]], [[linear-approximation-table|LAT]]) — это два «зеркальных» метода криптоанализа, и метрики $\delta$ и $N$ — независимы.

## Связь с лавинным эффектом

Если производные $f'_{e_i}$ по одиночным направлениям часто принимают значение 1 — функция обладает хорошим **лавинным эффектом** (изменение одного бита входа меняет много битов выхода). Это родственно критерию SAC.

## Реализация

Отдельной функции «производная по направлению» в коде нет — производная вычисляется неявно при построении DDT:

- `sbox/ddt.go:14` — выражение `b := sb.s[x^a] ^ sb.s[x]` — это и есть значение $S'_a(x)$.
- `sbox/ddt.go:8` — `computeDDT()` агрегирует распределение $S'_a$ по всем ненулевым $a$ в [[differential-uniformity|DDT]].

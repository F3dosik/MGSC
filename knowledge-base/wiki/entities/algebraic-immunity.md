# Алгебраическая иммунность (AI)

## Определение

**Алгебраическая иммунность** $AI(f)$ — минимальная [[algebraic-degree|алгебраическая степень]] ненулевой функции $g \in \mathcal{F}_n$, которая является [[annihilator|аннигилятором]] либо $f$, либо $f \oplus 1$:
$$AI(f) = \min \{ \deg g : g \neq 0,\ f \cdot g = 0 \text{ или } (f \oplus 1) \cdot g = 0 \}.$$

## Граница

$$AI(f) \leq \lceil n/2 \rceil.$$

Для $n=8$ — максимальное значение $AI = 4$.

## Криптографический смысл — [[algebraic-attack|алгебраическая атака]]

Низкая $AI$ → шифр сводится к разрешимой системе уравнений низкой степени → **алгебраическая атака** (Courtois, Meier, 2003). Поэтому в современных шифрах требуют $AI = \lceil n/2 \rceil$ или близко к нему. Целевой порог 2-й курсовой ([[thesis-statement]]): $AI \geq 3$.

Высокая [[algebraic-degree|алгебраическая степень]] **не гарантирует** высокую AI: бывает $\deg f = n-1$, но $AI(f) = 1$ (если у $f$ есть линейный аннигилятор). Поэтому $\deg$ и $AI$ — **независимые критерии**, защищающие от разных атак (см. [[attacks-overview]]).

## Алгоритм вычисления

Перебор $d = 1, 2, \dots, \lceil n/2 \rceil$. Для каждой $d$:
1. Сформировать все мономы степени $\leq d$ — их $\binom{n}{0} + \binom{n}{1} + \cdots + \binom{n}{d}$ штук.
2. Построить матрицу: строки — точки носителя $f$ (или $f \oplus 1$), столбцы — значения мономов в этих точках.
3. Если ранг матрицы меньше числа столбцов → существует ненулевое ядро → существует аннигилятор степени $\leq d$.

Первое $d$, на котором ядро найдено, — это $AI(f)$.

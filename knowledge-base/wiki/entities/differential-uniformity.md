# Дифференциальная равномерность и DDT

## DDT — таблица разностного распределения

Для S-блока $S: \mathbb{Z}_2^n \to \mathbb{Z}_2^n$:
$$DDT(a, b) = |\{x \in \mathbb{Z}_2^n : S(x \oplus a) \oplus S(x) = b\}|.$$

Это $2^n \times 2^n$ таблица; строка $a$ описывает распределение значений [[directional-derivative|производной по направлению]] $S'_a$.

### Свойства (Heys 2002, §4.2)

Для биективного S-блока $S: \mathbb{F}_2^n \to \mathbb{F}_2^n$:

1. **Сумма по строке** $\sum_b DDT(a, b) = 2^n$ — все $x$ дают какое-то $\Delta Y$.
2. **Сумма по столбцу** $= 2^n$ (для биективного S-блока).
3. **Все элементы чётные.** Если пара $(X', X'')$ даёт разность $b$, то и пара $(X'', X')$ — она же; поэтому пары идут парами.
4. **$DDT(0, 0) = 2^n$**: нулевая входная разность $\to$ нулевая выходная всегда.
5. **$DDT(0, b) = 0$ для $b \neq 0$**: то же условие — биективность исключает другие выходные разности.
6. **«Идеальная» таблица** (все элементы $= 1$, давая $P(\Delta Y \mid \Delta X) = 1/2^n$) **математически невозможна** — противоречит свойствам 1, 3.
7. **Ключ не влияет на DDT.** Для keyed S-блока $S_K(W) = S(W \oplus K)$ DDT совпадает с DDT unkeyed S-блока, так как $\Delta W = W' \oplus W'' = X' \oplus X''$ — ключевые биты сокращаются.

## Дифференциальная равномерность $\delta$

$$\delta(S) = \max_{a \neq 0,\ b} DDT(a, b).$$

Чем меньше $\delta$, тем равномернее распределение производных и тем устойчивее $S$ к [[differential-cryptanalysis|дифференциальному криптоанализу]] (Biham–Shamir, 1990).

## Границы

- $\delta \geq 2$ для биективных S-блоков (из чётности элементов и того, что строка непостоянна).
- S-блоки с $\delta = 2$ называются **APN** (Almost Perfect Nonlinear). Существуют для нечётных $n$; для чётных $n=8$ существование биективных APN — открытая проблема.
- Для биективных S-блоков 8×8 минимально достижимое значение $\delta = 4$.

AES использует мультипликативную инверсию в $\mathbb{F}_{2^8}$ + аффинное преобразование → $\delta = 4$.

## Связь с другими метриками

- [[directional-derivative]] — DDT агрегирует значения $S'_a$ по всем направлениям.
- [[nonlinearity]] и $\delta$ независимы: высокая NL не гарантирует малую $\delta$ и наоборот. Поэтому fitness-функции для генерации обычно комбинируют обе.

## Связь с криптоанализом

DDT — рабочий инструмент [[differential-cryptanalysis|дифференциального криптоанализа]] (Biham-Shamir). Атакующий ищет дифференциальную характеристику с высокой вероятностью, склеивая дифференциалы отдельных S-блоков. Чем меньше $\delta(S)$ — тем меньше вероятность характеристики.

Параллельная атака — [[higher-order-differential-attack|higher-order differential]] — эксплуатирует **алгебраическую структуру** S-блока через производные высоких порядков, защищается [[algebraic-degree|алгебраической степенью]].

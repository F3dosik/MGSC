# Таблица линейных аппроксимаций (LAT)

## Определение

Для S-блока $S: \mathbb{F}_2^n \to \mathbb{F}_2^m$:
$$LAT[\alpha, \beta] = |\{x \in \mathbb{F}_2^n : (\alpha, x) \oplus (\beta, S(x)) = 0\}| - 2^{n-1}.$$

Это $2^n \times 2^m$ таблица. Элемент $LAT[\alpha, \beta]$ показывает **смещение** (bias) линейной аппроксимации с входной маской $\alpha$ и выходной маской $\beta$. Для идеального S-блока среднее $LAT = 0$.

## Линейность S-блока

$$L(S) = \max_{\alpha \neq 0,\ \beta \neq 0} |LAT[\alpha, \beta]|.$$

Чем меньше $L(S)$, тем устойчивее S-блок к [[linear-cryptanalysis|линейному криптоанализу]].

## Связь LAT с компонентной булевой функцией

Для фиксированных $\alpha, \beta$ определим аппроксимирующую булеву функцию:
$$f_{\alpha,\beta}(x) = (\alpha, x) \oplus (\beta, S(x)).$$

Тогда:
$$LAT[\alpha, \beta] = 2^{n-1} - w(f_{\alpha,\beta}),$$
где $w$ — [[boolean-function-basics|вес]] функции.

## Теорема: связь линейности и нелинейности

$$L(S) = 2^{n-1} - N(S),$$
где $N(S) = \min_{\beta \neq 0} N(f_\beta)$ — [[nonlinearity|нелинейность]] S-блока, $f_\beta(x) = (\beta, S(x))$ — компонентная функция (см. [[sbox-as-boolean]]).

**Идея доказательства** (полное — `raw/coursework-2/content.tex:357–396`):
1. $f_{\alpha,\beta} = (\alpha, x) \oplus f_\beta$, поэтому $w(f_{\alpha,\beta}) = d(f_\beta, (\alpha, x))$.
2. $\min\{d(f_\beta, (\alpha, x)), d(f_\beta, (\alpha, x) \oplus 1)\} = 2^{n-1} - |LAT[\alpha, \beta]|$.
3. $N(f_\beta) = \min_g d(f_\beta, g)$ по всем аффинным $g = 2^{n-1} - \max_\alpha |LAT[\alpha, \beta]|$.
4. $N(S) = \min_\beta N(f_\beta) = 2^{n-1} - \max_{\alpha, \beta} |LAT[\alpha, \beta]| = 2^{n-1} - L(S)$.

## Свойства таблицы (Heys 2002, §3.3)

Для биективного S-блока $S: \mathbb{F}_2^n \to \mathbb{F}_2^n$:

1. **Угол $(0, 0)$:** $LAT[0, 0] = +2^{n-1}$ (тривиальное «$0 = 0$» с вероятностью 1).
2. **Первая строка** (кроме $[0,0]$): все нули. Линейная комбинация **только выходных** битов биективного S-блока сбалансирована — даёт $0$ и $1$ ровно поровну.
3. **Первый столбец** (кроме $[0,0]$): все нули. Аналогично для линейной комбинации **только входных** битов.
4. **Сумма любой строки или столбца** равна $\pm 2^{n-1}$.
5. Bias аппроксимации $(\alpha, \beta) = LAT[\alpha, \beta] / 2^n$.

## Связь с [[walsh-hadamard|ПУА]]

Для компонентной функции $f_\beta$:
$$LAT[\alpha, \beta] = \tfrac{1}{2}\hat{f}_\beta(\alpha).$$

Поэтому **LAT = массив коэффициентов ПУА всех компонентных функций**, делённый пополам. Это даёт алгоритм $O(2^m \cdot n \cdot 2^n)$: для каждого $\beta$ берём $f_\beta$, делаем FWHT.

## Следствие для генерации

Минимизация $L(S)$ ⇔ максимизация $N(S)$. Поэтому в [[fitness-function-sbox|fitness-функции]] используется штраф за низкую $N(S)$, а не за высокую $L(S)$ — это эквивалентно.

## Реализация

В коде **не реализована** — есть только агрегированная $N(S)$ через `sbox/analysis.go`. Если потребуется полная LAT (например, для распределения нелинейностей координатных функций, см. [[sbox-as-boolean]]), нужно реализовать отдельно. Запланировано в [[backlog]].

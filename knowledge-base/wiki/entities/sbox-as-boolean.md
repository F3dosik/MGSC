# S-блок как векторная булева функция

## Определение

**S-блок** (substitution box) размера $n \times m$ — отображение
$$S: \mathbb{F}_2^n \to \mathbb{F}_2^m.$$

В современных шифрах чаще всего $n = m = 8$ (8-битные S-блоки, см. [[reference-sboxes-metrics]]) или $n = m = 4$ (Serpent).

Для большинства симметричных шифров требуется **биективность** $S$.

## Компонентные (координатные) булевы функции

Для каждой ненулевой выходной маски $\beta \in \mathbb{F}_2^m \setminus \{0\}$ определена компонентная функция:
$$f_\beta(x) = (\beta, S(x)) = \bigoplus_{i: \beta_i = 1} S_i(x),$$
где $S_i: \mathbb{F}_2^n \to \mathbb{F}_2$ — $i$-я координата выхода.

Каждая $f_\beta$ — обычная [[boolean-function-basics|булева функция]] $\mathbb{F}_2^n \to \mathbb{F}_2$. Всего их $2^m - 1$ (исключая нулевую маску). Для $n = m = 8$ — **255 компонентных функций**.

## Агрегация метрик S-блока через компоненты

Большинство криптографических характеристик S-блока определяются как min/max по компонентам:

| Метрика S-блока | Через компоненты | Реализация |
|---|---|---|
| Нелинейность $N(S)$ | $\min_{\beta \neq 0} N(f_\beta)$ | `sbox/analysis.go:27` |
| Алгебраическая степень $\deg(S)$ | $\max_{\beta \neq 0} \deg(f_\beta)$ | `sbox/analysis.go:36` |
| Алгебраическая иммунность $AI(S)$ | $\min_{\beta \neq 0} AI(f_\beta)$ | `sbox/algebraic.go:6` |

[[differential-uniformity|Дифференциальная равномерность]] $\delta(S)$ определяется напрямую по таблице $S$ через DDT, не через компоненты.

## Свойство сбалансированности

> [!info] Ключевое следствие биективности
> Для **биективной** S-функции каждая ненулевая компонента $f_\beta$ автоматически [[balancedness|сбалансирована]]: $w(f_\beta) = 2^{n-1}$.
>
> Доказательство: если $S$ биективна, то для любой $\beta \neq 0$ функция $f_\beta = (\beta, S(x))$ при равномерном $x$ распределена так же, как $(\beta, y)$ при равномерном $y$, а $(\beta, y)$ при $\beta \neq 0$ — линейная функция, принимающая 0 и 1 в равных долях.

При генерации **биективных** S-блоков (через swap двух элементов) сбалансированность компонент гарантируется и не требует контроля в fitness-функции.

## Распределение нелинейностей координатных функций

Помимо $N(S) = \min_\beta N(f_\beta)$, полезные характеристики:

- **Средняя нелинейность:** $\overline{N}(S) = \frac{1}{2^m - 1} \sum_\beta N(f_\beta)$.
- **Количество компонент с минимальной NL:** $N_{\min} = |\{\beta : N(f_\beta) = N(S)\}|$.

Малое $N_{\min}$ → у атакующего меньше «удобных» компонент для линейной аппроксимации. Это вторичная метрика, полезна для тонкого сравнения двух S-блоков с одинаковой $N(S)$.
